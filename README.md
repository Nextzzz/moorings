# The Moorings — landing page

Static site. Deploy to GitHub Pages:

1. Create a repo, upload the contents of this folder (index.html, .nojekyll, assets/).
2. Settings → Pages → Source: Deploy from a branch → main / (root) → Save.
3. Site goes live at https://<user>.github.io/<repo>/ in ~1 minute.

Replace the phone number (+353719667622), prices and opening hours in index.html before launch.
